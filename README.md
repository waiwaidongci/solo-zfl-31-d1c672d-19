# 手工织锦纹样排版台 · 离线版权水印与溯源核验

直接用浏览器打开 `index.html` 即可使用，**全程离线**，不依赖网络与第三方库。

## 功能

- 原有功能：经纬网格绘制（单点/十字/小菱形、拖动连填）、8 色色线用量统计、重复单元预览、断线风险提示、撤销重做、本机保存、JSON 导出。
- 新增离线版权能力：
  - **登记**：作者编号（1–32767）、授权范围（6 类）、有效期（起始月 + 月数，0 为长期）、方案指纹（SHA-256，原图与水印图两份）。
  - **水印嵌入**：水印藏在网格的 2×2 格点块中，只在块内重排明暗两类颜色，
    **每种色线的全局数量一格不差**；块布局由网格尺寸确定性派生，与图案内容无关。
  - **抗变形恢复**：盲检测支持 **裁切、缩放、旋转（90/180/270°）、水平/垂直翻转、颜色量化**
    及它们的组合；自动搜索 8 个朝向、候选原尺寸、裁切偏移与块相位。
  - **核验面板**：显示提取结果（作者/范围/期限）、逐位可信度、登记作者、授权期限状态
    （有效/已过期/未生效/长期）、几何检测结果；再列出**被改格坐标与前后色号**、
    **裁切缺失、无法确认的格及原因**，并画出差异图（红框=改格、黄框=缺格）。
  - 判定：`valid` 通过、`valid_partial` 裁切但可见部分完全一致、`tampered` 篡改、
    `damaged` 损坏（部分字段/格点无法确认）、`orphan` 有水印但本机无登记、`unknown` 无法确认。
  - **写保护**：水印不匹配时核验结果不会覆盖登记原方案；登记册导入同编号异指纹条目一律拒绝。
  - 编辑、撤销重做、保存、JSON/PNG 导出、方案/登记册导入后，水印绑定状态自动同步。
  - **批量连续核验**：一次选择多个 JSON 方案，逐条给出结果与原因，200 个方案在普通机器上约 1 秒内完成。
  - **图像核验**：可直接选择 PNG/翻拍照片，自动检测网格线、恢复格点颜色后核验。
  - 桌面三栏、手机单栏自适应，录入、导出、核验、查看差异均可在手机浏览器完成。

## 文件结构（算法与页面分离）

```
index.html            页面结构
css/style.css         样式（含响应式）
js/watermark.js       核心算法：指纹、系统外码、嵌入、8朝向/裁切盲检测、核验（无 DOM 依赖）
js/registry.js        离线登记册：登记/写保护/持久化/导入导出/批量核验（可注入存储）
js/raster.js          图像通道：网格渲染、几何/颜色攻击模拟、网格自动检测与格点恢复
js/app.js             页面交互
test/run-tests.js     Node 自动化测试（零依赖）
tests.html            本机浏览器用例记录页（真实 canvas 通道，结果可导出/存本机）
```

## 测试

- 自动化：`npm test` 或 `node test/run-tests.js`（141 项，零依赖）。
  覆盖：合法、损坏、变形（裁切/缩放/旋转/翻转/量化/组合）、篡改（改格、伪造水印、写保护）、
  无解（空白、彩条、残片、孤儿水印、重噪声、超尺寸），以及色线数量不变、
  登记册导入拒绝损坏、200 方案连续核验性能。
- 浏览器：打开 `tests.html` 自动运行 33 个用例（含真实 `<canvas>` 渲染与恢复），
  可导出 JSON 记录、保存带结果的 HTML，历史结果存 localStorage。

## 水印编码简述

- 载荷 43 位：8 位魔数 + 15 位作者编号 + 3 位授权范围 + 11 位起始月（自 2000-01）+ 6 位月数。
- 编成 126 位 GF(2) 系统码（43 信息位 + 83 个稀疏 XOR 校验位），
  裁切造成的无票位（删失）可用校验方程经 BigInt 高斯消元补解；
  块序循环承载码字，同尺寸下重复块多数表决，可纠正个别改格造成的错票。
- 每块 2 位：按块内暗色格数 d（1/2/3）映射到“唯一暗格/亮格位置”或“暗格组合”，嵌入只做同色类置换。

## 数据与隐私

所有登记与核验数据仅保存在本机浏览器 localStorage 与用户主动导出的文件中，不上传任何服务器。
